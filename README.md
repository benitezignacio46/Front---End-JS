# ITB - Libros Usados

Sitio web de una librería ficticia de libros usados, creado como proyecto
final del curso. El objetivo del sitio es mostrar un catálogo de libros
en venta, reseñas de clientes, y permitir el contacto con la librería
a través de un formulario funcional.

## Páginas

- **index.html** — Inicio: presentación de la librería.
- **productos.html** — Catálogo de libros disponibles (organizado con Flexbox).
- **resenas.html** — Reseñas de clientes (organizado con Grid).
- **contacto.html** — Formulario de contacto (con Formspree) y mapa de ubicación.

## Tecnologías utilizadas

- HTML5 semántico (header, nav, main, section, footer)
- CSS3 (Flexbox, Grid, Media Queries, Google Fonts)
- Formspree para el envío de datos del formulario de contacto
